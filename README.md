# vioraSAVE

Viora Studio Tools - набор бесплатных браузерных инструментов для повседневных задач с файлами. Без регистрации, без рекламы, без лимитов.

6 инструментов:

📄 PDF — конвертация в JPG/PNG и обратно, объединение, разделение, сжатие, генерация документов через Viora AI

🖼 Фон — удаление фона с фото за пару секунд, всё локально в браузере

⬇ Видео — скачивание с TikTok, VK, Twitter/X, Instagram, Reddit, Twitch и ~1000 других площадок

🎨 Изображения — сжатие, конвертация форматов (JPG/PNG/WebP/AVIF), обрезка, ресайз, распознавание текста (OCR)

📱 QR-код — создание со своими цветами и сканирование через камеру или картинку

🎬 Запись — захват экрана и извлечение аудио из видео

Технически: чистый HTML + CSS + JavaScript, три файла, без сборщиков и npm. Тяжёлые библиотеки подгружаются по необходимости. Для скачивания видео — собственный yt-dlp бэкенд.
